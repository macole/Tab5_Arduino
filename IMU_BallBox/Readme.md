# IMU_BallBox - ボール物理シミュレーション

M5Stack Tab5のIMUセンサーを使用したボール物理シミュレーションプログラムです。

## 📋 概要

デバイスを傾けると、IMUの加速度データに基づいてボールが物理法則に従って動きます。DMA部分更新により滑らかで高速なアニメーションを実現しています。

## 🔧 必要なハードウェア

- M5Stack Tab5

## 📚 必要なライブラリ

- **M5Unified**: M5Stack統合ライブラリ
  ```bash
  arduino-cli lib install "M5Unified@0.2.10"
  ```

## 🚀 セットアップ

### ボード設定
- Board: ESP32P4 Dev Module
- USB CDC on boot: Enabled
- Flash Size: 16MB (128Mb)
- Partition Scheme: Custom
- PSRAM: Enabled（必須）

### プログラムのアップロード
Arduino IDEまたはArduino CLIでプログラムをアップロードしてください。

## 💻 使用方法

1. プログラムをアップロード
2. デバイスを傾けると、画面内のボールが動きます
3. ボールは画面の端で跳ね返ります
4. 画面左上にボールの位置と速度が表示されます

## 📊 主な機能

### 物理シミュレーション
- **重力と慣性**: 実際の物理法則に基づいた動き
- **減衰**: 摩擦による速度の減少
- **壁反発**: 画面端での跳ね返り（エネルギー損失あり）
- **速度制限**: 異常な速度を防止

### IMUセンサー連動
- **200Hz更新**: 高精度な加速度データ取得（5ms間隔）
- **軸マッピング**: 画面回転（270度）に対応した座標変換
- **リアルタイム表示**: 位置と速度を画面に表示

### 高速描画
- **スプライト**: 1280x720のオフスクリーンバッファ（PSRAM使用）
- **DMA部分更新**: 変更領域のみを転送（全画面転送の約1/10）
- **動的マージン**: ボールの速度に応じた更新領域の最適化
- **60FPS**: 滑らかなアニメーション

## 🎮 操作方法

- **デバイスを傾ける**: ボールが傾きの方向に動きます
- **デバイスを振る**: ボールが加速します
- **デバイスを静止**: ボールは減衰して停止します

## 🔍 プログラムの構造

### 初期化フロー
1. ハードウェア初期化（M5Unified）
2. スプライト作成（1280x720、PSRAM使用）
3. IMU初期化
4. ボール初期位置設定（画面中央）
5. 初期画面描画

### メインループ
1. **物理計算**: IMUデータから速度・位置を更新
2. **境界チェック**: 画面端での反発処理
3. **スプライト描画**: ボールとデバッグ情報を描画
4. **DMA転送**: 変更領域のみを画面に転送
5. **位置更新**: 次回の部分更新のため前回位置を記録

## 📝 主要なパラメータ

### 物理パラメータ
```cpp
const float ACCEL_SCALE = 2.0;        // 加速度の感度
const float DAMPING = 0.95;           // 摩擦係数
const float BOUNCE_DAMPING = 0.8;     // 壁反発時の減衰
const float VELOCITY_LIMIT = 20.0;    // 速度の上限
```

### 描画設定
```cpp
const int UPDATE_INTERVAL_MS = 16;    // 更新間隔（60FPS）
const int BALL_RADIUS = 20;           // ボールの半径
```

### IMU設定
```cpp
const unsigned long IMU_UPDATE_INTERVAL_US = 5000;  // 5ms = 200Hz
```

## 🛠️ カスタマイズ

### ボールの感度を変更
`ACCEL_SCALE`の値を変更してください（大きいほど敏感）。

### 更新速度を変更
`UPDATE_INTERVAL_MS`の値を変更してください（小さいほど速い）。

### デバッグ情報の表示/非表示
```cpp
const bool SHOW_DEBUG_INFO = true;  // falseで非表示
```

## 🔧 技術的な詳細

### DMA部分更新の仕組み
1. スプライト上で前回位置を消去
2. 新しい位置にボールを描画
3. 前回位置と現在位置を含む最小矩形を計算
4. その矩形領域のみをDMA転送
5. デバッグ情報も別途DMA転送

### 動的マージンの計算
```cpp
int dynamicMargin = BALL_RADIUS + 8 + (distance) / 4;
```
- ベースマージン: `BALL_RADIUS + 8`
- 距離に応じて拡大: `distance / 4`
- 上限: `BALL_RADIUS + 25`

### IMU座標系と画面座標系のマッピング
```cpp
ball.velX -= imuData.accel.y * ACCEL_SCALE;  // 左右
ball.velY += imuData.accel.x * ACCEL_SCALE;  // 上下
```
画面回転（270度）に対応した座標変換を実装。
