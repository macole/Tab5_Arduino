# GameOfLife - ライフゲーム

Conway's Game of Life（ライフゲーム）をM5Stack Tab5で実装したプログラムです。

## 📋 概要

このプログラムは、1970年にイギリスの数学者ジョン・ホートン・コンウェイによって考案されたセルオートマトン「ライフゲーム」を実装しています。セル（細胞）の生死のルールに基づいて、世代ごとにパターンが進化していきます。

## 🔧 必要なハードウェア

- M5Stack Tab5

## 📚 必要なライブラリ

- **M5Unified**: M5Stack統合ライブラリ
  ```bash
  arduino-cli lib install "M5Unified@0.2.10"
  ```

## 🚀 セットアップ

### ボード設定
- Board: ESP32P4 Dev Module
- USB CDC on boot: Enabled
- Flash Size: 16MB (128Mb)
- Partition Scheme: Custom
- PSRAM: Enabled

### プログラムのアップロード
Arduino IDEまたはArduino CLIでプログラムをアップロードしてください。

## 💻 使用方法

プログラムをアップロードすると、自動的にライフゲームが開始されます。

1. タイトル画面が2秒間表示されます
2. ランダムな初期パターンが生成されます
3. ライフゲームのルールに従ってパターンが進化します
4. パターンが安定する（変化がなくなる）と、新しいパターンで再開します

## 📊 機能

### セルオートマトン
- ライフゲームのルールを完全実装
- 周囲8マスの状態を確認して次世代を計算

### 表示機能
- **画面サイズ自動調整**: Tab5の画面（1280x720）に最適化
- **ダブルバッファリング**: 2つのキャンバスでスムーズな表示
- **高速描画**: 変更があった部分のみを更新
- **カラー深度8bit**: メモリ効率を考慮した表示

### 自動ループ
- パターンが安定したら新しいパターンを自動生成
- ランダムな初期パターンで毎回異なる進化を観察可能

## 🎮 ライフゲームのルール

### 基本ルール
各セルは、周囲8マスの生存セル数に基づいて次世代の状態が決定されます：

1. **生存継続**: 生きているセルが2個または3個の隣接セルを持つ → 次世代も生存
2. **誕生**: 死んでいるセルがちょうど3個の隣接セルを持つ → 次世代で誕生
3. **死亡**: 上記以外の場合 → 次世代で死亡

### コード実装
```cpp
// ライフゲームのルール
bool flg = (neighbors == 3) || (neighbors == 2 && old_buf[idx]);
```
- `neighbors == 3`: 周囲に3個 → 誕生または生存
- `neighbors == 2 && old_buf[idx]`: 周囲に2個かつ現在生存 → 生存継続

## 🔍 プログラムの動作

### 初期化フロー
1. M5Unifiedの初期化
2. 画面の色深度とモードを設定
3. 横向き表示に設定（1280x720）
4. キャンバスサイズを計算（最大192x160セル）
5. 2つのキャンバスを作成（ダブルバッファリング用）
6. タイトル画面を表示

### メインループ
1. 初期パターンをランダムに生成（1/6の確率で生存セル）
2. ライフゲームのルールに基づいて世代を進める
3. 変更があった部分のみを画面に描画
4. パターンが安定したら（変化がなくなったら）新しいパターンで再開

## 📝 コードの主要なポイント

### セルサイズの自動調整
```cpp
// 画面サイズに応じて最適なセル数を計算
int width = M5.Display.width() / ++z;  // 最大192セル
int height = M5.Display.height() / ++z; // 最大160セル
```

### ダブルバッファリング
```cpp
M5Canvas canvas[2];  // 2つのキャンバス
bool flip = !flip;   // バッファを切り替え
```

### 高速描画
```cpp
// 変更があった部分のみを描画
if (flg != new_buf[idx]) {
  M5.Display.fillRect(x * xz, y * yz, xz, yz, flg ? TFT_WHITE : TFT_BLACK);
  ++diff;
}
```

### トーラス構造
画面の端は反対側と接続されており、セルが画面端で途切れることなく進化します。

## 🎨 カスタマイズ

### 初期パターンの密度変更
```cpp
if (random(6) == 0) { ... }  // 1/6の確率を変更可能
```

### セルサイズの制限変更
```cpp
while (width > 192);   // 最大幅を変更可能
while (height > 160);  // 最大高さを変更可能
```
